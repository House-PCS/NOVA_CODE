# 01 系统总览与架构

## 1.1 CPU2 在整机中的角色

本工程运行于 **TI TMS320F28375D** 双核 DSP 的 **CPU2**。

| 核 | 主要职责 |
|----|----------|
| CPU1 | ADC 采样、主控制、向 CPU2 发送采样指针/使能标志/STS 命令，读取电量与状态结果 |
| CPU2（本工程） | 五通道三相电量计算（PLL/正负序/RMS/功率）、STS 并网状态机胶水、母线/中点电压/漏电流辅助量、ISR 负载与心跳上报 |

**设计原则**：ADC 与主控在 CPU1；CPU2 做“重计算”，通过 IPC 中断与约 20 kHz 控制节拍对齐，经 GS RAM / 消息 RAM 回传结果。

## 1.3 启动与初始化顺序（`main`）

严格顺序如下：

1. **`SysCtrlCpu2_Init()`**  
   - 关看门狗  
   - Flash 构建时：把 `.TI.ramfunc` 拷到 `RAMD1` 并 `InitFlash()`  
   - 仅打开 CPU Timer0/1/2 时钟  
   - **不配置 PLL**（双核时钟由 CPU1 负责）

2. **`DELAY_MS(500)`** — 给对端就绪留窗口

3. **关全局中断**，清 `IER/IFR`，初始化 PIE 控制与向量表

4. **`DualCore_HandshakeCpu2(3000 ms)`**  
   - 等待 CPU1 置 `IPC_FLAG 0x10`（CPU1 ready）  
   - ACK  
   - 等待 GS master 掩码 `0x17`  
   - 置 CPU2 ready `0x20`  
   - 失败则死循环

5. **`DualCore_ConfigGsRamAccessProtect()`** — GS3/GS4：CPU 可写，DMA 写保护

6. **`DualDataShare_Init()`** — 向 `0x3F800` 写入电量接口/STS/调试缓冲地址，清心跳与 ISR 计数

7. **`Ph3CalcIfcUpdate_Init()`** — 清零 GS4 中的 `gstPh3CalcIfcUpdate`

8. **`DevDcr_ExchangeAddress(100 ms)`** — 轮询 CPU1 消息中的 ADC / STS 输入地址（超时仍继续）

9. **`CpuControl_Ph3CalcInit()`** — 五通道 + 母线滤波器初始化

10. **`MidVolAndRcmuRms_Init()`** — 漏电流一阶 LPF 初始化

11. **`CpuTimer_Init()`** — Timer2=1 ms 系统节拍；Timer1 用于 ISR 测时（自由运行）

12. **`CpuIntFunInit()`** — 注册 IPC ISR 回调并使能 IPC0 中断

13. **`CpuControl_Ph3StsInit()`** — AlgoFw STS + Adjust 初始化

14. **`EINT; ERTM;`** — 开全局中断与实时调试

15. **主循环**  
    - `CpuTimerFlag()` 生成软定时标志  
    - 每圈：`CpuControl_Ph3DataUpdate()`（慢路径拷贝电量 + STS 慢更新）  
    - 1 ms：`CpuControl_Ph3FlagUpdate()`（通道使能 + STS 命令镜像）

## 1.4 双核通信架构

### 1.4.1 消息 RAM（固定地址，无需链接 section）

| 方向 | 地址 | 结构体 |
|------|------|--------|
| CPU2 → CPU1 | `0x0003F800` | `DevDct_Cpu2ToCpu1Msg_t` |
| CPU1 → CPU2 | `0x0003FC00` | `DevDct_Cpu1ToCpu2Msg_t` |

**CPU2→CPU1 字段含义：**

| 字段 | 含义 |
|------|------|
| `cpu2_ph3_ifc_addr` | `gstPh3CalcIfcUpdate` 地址（GS4 电量结果） |
| `isr_run_cnt` | 本次 IPC ISR 执行耗时（CpuTimer1 tick） |
| `isr_idle_cnt` | 距上次 ISR 退出的空闲时间 |
| `heartbeat_cnt` | 运行心跳（每个 IPC 周期会 +2，见下文） |
| `sts_output_addr` | `_gstStsOutput` 地址 |
| `cpu2_debug_data_addr` | 调试数据缓冲地址 |

**CPU1→CPU2 字段含义：**

| 字段 | 含义 |
|------|------|
| `cpu1_adc_result_addr` | `CpuAdc_t*` ADC 结果 |
| `grid/gen/load/inv/ct` | 各通道 `volt_pll / curr_pll / power_calc` 使能 |
| `sts_input_addr` | STS 命令输入结构地址 |

### 1.4.2 GS 共享 RAM

| Section | 物理区 | 用途 |
|---------|--------|------|
| `ramgs0` | RAMGS3 (`0xF000`) | 主要由 CPU1 放 ADC 等 |
| `ramgs1` | RAMGS4 (`0x10000`) | CPU2：`gstPh3CalcIfcUpdate`、`_gstStsOutput` |

### 1.4.3 触发链

```
CPU1 采样完成
  → 置 IPC_DUAL_FLAG_CPU1_EVENT (0x1)
  → CPU2 IPC0 中断 CPU_Interrupt
  → 回调 CpuIntServiceFun
       ├─ 心跳 / 测时
       ├─ Ph3CalcRun_Run()   （五通道算法 + 角度快写 + 母线 + 中点/漏电流）
       └─ Ph3_Sts_Run()      （STS 快路径）
  → ACK IPC + PIE Group1
  → CPU1 读 GS4 电量与 STS 输出
```

### 1.4.4 心跳特殊说明

`DualDataShare_Ph3IfcRunDone()` 在 **ISR 入口**（`CpuIntServiceFun`）与 **`Ph3CalcRun_Run` 末尾**各调用一次，因此**每个 IPC 周期心跳约 +2**。CPU1 判活时应按此理解。

## 1.5 双节拍：快路径 vs 慢路径

| 路径 | 触发 | 频率量级 | 典型工作 |
|------|------|----------|----------|
| 快路径 | IPC ISR | ~20 kHz | 五通道 `ChannelRun`、角度写 GS4、母线滤波、中点/漏电流累加、STS 瞬时运行 |
| 慢路径 | main 轮询 | ≤1 kHz | RMS/功率整包拷贝到 GS4、STS 告警/故障慢检查、1 ms 使能/命令同步 |

**设计意图**：角度等控制急需量在 ISR 立即可见；大块 RMS/功率在后台拷贝，降低共享区读写撕裂窗口。

## 1.6 五通道三相计算总览

| 通道变量 | 电压源 | 电流源 | PF 模式 | PLL 模式 |
|----------|--------|--------|---------|----------|
| `s_grid` | 电网 Vabc | 电网 Iabc | NORMAL | 正序 |
| `s_gen` | 柴发 Vabc | 柴发 Iabc | NORMAL | 正序 |
| `s_load` | 负载 Vabc | 负载 Iabc | NORMAL | 正序 |
| `s_inv` | 逆变 Vabc | 逆变 Iabc | **INV** | 正序 |
| `s_ct` | **电网** Vabc | CT Iabc | NORMAL | 正序 |

单通道内部流水线：

```
瞬时采样
 → [使能] 电压正负序 + SRF-PLL
 → [使能] 电流正负序 + SRF-PLL（Park 角用电压 theta）
 → [使能] 功率因数 → 分相周期 RMS/有功 → 无功/合相 → 分相频率
```

## 1.7 CLA 协处理器现状

| 项目 | 状态 |
|------|------|
| `cla_control.cla` | Task1～8 为空壳/清中断占位 |
| `cla_cpu_share` | 无共享变量 |
| `interrupt.c` | **故意不使能 CLA** |
| 链接脚本 | 已预留 Cla1Prog / LS 区 |

**结论：当前全部三相算法在 CPU2 C28x FPU 上运行；CLA 为后续扩展骨架。**

## 1.8 STS（同步并网）数据流

```
CPU1 StsInputStatus（使能/并离网命令/清故障）
    --1ms FlagUpdate--> _gstStsInputStatus
IPC ISR（sts_run_en=1）:
  瞬时电压 / theta / w0 → Sts_Set_InputData
  Sts_Run + Sts_Adjust_Run
  输出 adjust_w / adjust_volt
  Sts_Get_OutputData → _gstStsOutput.sts_output
后台 DataSlowUpdate:
  选 grid 或 gen 的 RMS 作 connected_*
  Warn/Fault Check → 刷新 err/warn/连接状态到 _gstStsOutput
CPU1 经 sts_output_addr 读取
```

> STS 核心算法位于外部 **AlgoFw** 库，本仓库仅做采样装配与输出打包。

## 1.9 热路径与 RAM 执行

大量 ISR 相关函数通过：

```c
#pragma CODE_SECTION(函数名, ".TI.ramfunc");
```

链接到 Flash 加载、**RAMD1 运行**，避免 Flash wait-state 拖慢 20 kHz 路径。

## 1.10 模块依赖总图

```
main
 ├─ SysCtrlCpu2 / DualCore / DualDataShare / Ph3CalcIfc / DevDcr
 ├─ Ph3CalcRun_Init / MidVol / CpuTimer / Interrupt / Ph3_Sts_Init
 └─ loop: DataUpdate + FlagUpdate(1ms)

IPC ISR
 └─ CpuIntServiceFun
     ├─ DualDataShare 心跳 / ISR 测时
     ├─ Ph3CalcRun_Run
     │    ├─ DevDcr ADC
     │    ├─ Channel×5 (PosNeg→PLL→RMS→Power)
     │    ├─ InterfaceAngleUpdate → GS4
     │    ├─ Bus filter
     │    └─ MidVolAndRcmuRms_Run
     └─ Ph3_Sts_Run → AlgoFw → GS4 _gstStsOutput
```
