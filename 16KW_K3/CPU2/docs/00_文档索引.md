## 文档范围说明

### 已纳入（业务代码）

- `app/`：主程序、双核共享、三相运行、STS 胶水、中点/漏电流
- `algo/`：三相电量算法（PLL/正负序/RMS/功率/滤波/接口）及 CLA 空壳
- `driver/`：CPU2 最小系统、双核握手、IPC 中断、定时器、系统复位
- `middleware/`：Butterworth 滤波器
- `cmd/`：Flash 链接脚本（业务内存布局相关）

### 已排除（原厂/第三方库）

- `include/`、`source/`：TI F2837xD 外设驱动与寄存器头文件
- `include/FlashAPI/`：Flash 编程 API
- `driver/cla1_math_library.lib`：CLA 数学库二进制
- `tool/` 下可执行工具与批处理

## 阅读建议

1. 先读 **01 系统总览**，建立双核分工与 20 kHz / 1 ms 双节拍概念。
2. 再读 **02 应用层**，理解“谁在何时调用谁”。
3. 然后读 **03 算法层**，掌握每个电量计算公式与状态机。
4. 需要对照实现时查阅 **附录 A/B/C** 完整源码。
