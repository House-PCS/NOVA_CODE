# 07 应用层：能量管理

对应源码：`app/energy_management/*`

---

## 1. 模块目标

在并网/离网/油机等场景下，根据工作模式、负载、CT、PV、电池与并网约束，计算：

- PV→母线功率设定  
- 电池充放功率目标  
- 电网/油机连接端有功设定  
- 逆变 P/Q 设定（再经温度降额、母线限功率、斜坡）

调度入口在主循环 **1 ms**：`EnergyManagementDataUpdate()` + `EnergyScheduling()`。

---

## 2. 数据与配置

### 2.1 `DeployInfo_t gstDeployInfo`

通信设定：工作模式、充放电使能、额定功率、并网重连时间、CT 方向等。

### 2.2 `EnergyManageData_t gstEnergyManageData`

实时温度、逆变状态、母线、电网/油机使能、负载、时间、斜坡参数。

### 2.3 典型额定（`energy_management_cfg`）

| 项目 | 典型值 |
|------|--------|
| Grid 输入 / 输出 | 24 kW / 16 kW |
| 逆变并网 / 离网 | 16 kW / 17.5 kW |
| PV | 24 kW |
| 功率斜坡 | 约 2 W/周期 |
| 温度降额区间 | 见 temp_pwr_derate |

---

## 3. `pwr_ctrl_interface` — 输入装配

### 3.1 `PwrCtrl_Set_DeployFromComm`

从 `gstUdpPcsPara.udp_pcs_hold` 读模式、充放许可、功率上限、反送电、重连时间等；油机强制连接时可覆盖为 `EN_OIL_MODE`。

### 3.2 `PwrCtrl_Set_EnergyCtrlInput`

- 映射 PCS 状态到并离网枚举  
- 填充 PV、母线、电网、油机、CT、EPS 的 P/Q/S  
- 远端负载 ≈ `CT总有功 - 电网有功`  

### 3.3 `PwrCtrl_Set_DataInput`

- 由 PCS 状态设 grid/oil enable  
- 仅 Biz FSM Normal/Test 时 `inv_enable=1`  
- 写温度、电压、母线、时间、负载、斜坡  

### 3.4 `EnergyManagementDataUpdate`

1 ms 顺序调用上述三步。  
另提供 `GetDrmGridConnectEN` / `GetConnectTimeEN`（目前 `control_state` 未真正使用）。

---

## 4. `energy_manage` / `energy_ctrl` — 核心功率平衡

### 4.1 `EnergyManage_Run`

1. 输入空或逆变未使能 → 三路输出清零  
2. 拷贝输入  
3. `EnergyCtrlProcess()`  
4. 输出钳位：PV 0~24kW；Grid -16~24kW；Gen 0~16kW  

### 4.2 `_OnOffGridLimitCalc`

计算网/油机/电池/EV/逆变端口上下限：

**并网：**

- 入户功率、端口额定、逆变能力三重限制  
- 防逆流 / 削峰非卖电时禁止送网  
- 得到 `grid2pcs` 上下限  

**离网：**

- 禁止电网  
- 油机模式允许油机供电，最小约 100 W 防逆流  
- 再推 AC/DC/电池/EV 可行范围  

### 4.3 `_OnGridEnergyCtrlCalc`（按工作模式）

| 模式 | 电池目标思路 |
|------|----------------|
| 自发自用 | PV 优先，电池补负载，最后电网补 |
| 电池优先 | 目标最大充电 |
| 削峰-静态 | 类似自发自用但限制送网 |
| 削峰-买电 | 类似电池优先 |
| 削峰-卖电 | PV+电池满足最大并网目标 |

后续步骤：

1. `CertificationTest` 可覆盖电池 target  
2. 电池功率限幅  
3. 功率平衡得 grid target  
4. 超网侧限制：富余优先电池吸收，不够降 PV；不足优先电池放电  
5. PV 每周期尝试 +100W 扰动（受 PCS/PV 上限约束）  

### 4.4 `_OffGridEnergyCtrlCalc`

- 普通离网：PV+电池匹配 EPS  
- 油机离网：电池优先充电，油机补 EPS/电池，超限先电池吸收再降 PV  

### 4.5 `CertificationTest`

并网认证：硬限制、软限制、模拟断网、功率变化率等。部分“实际脱网动作”注释标明未接入。

### 4.6 `EnergyCtrlProcess`

按 `inv_stat`：

- 待机/解网：清输出  
- 离网：限值 + 离网调度  
- 并网：限值 + 并网调度  
- 过渡态：部分空或清输出  

### 4.7 实现注意

- `_GetEnergyInput` 为空函数  
- 存在 `if(1)` 强制路径  
- EV 上限比较方向需复核  
- `grid2pcs` 正负号约定复杂，联调时要统一符号规范

## 5. `pwr_ctrl_func` — 最终编排

`EnergyScheduling()`（1 ms）内部分频：

| 周期 | 模块 |
|------|------|
| 10 ms | `EnergyManage_Run` |
| 15 ms | `GridConnectTimeCtrl_Update` |
| 20 ms | `TempPwrDerate_Update` |
| 100 ms | `DrmPwrSched_Update` |
| 1 ms | `GridBusPwrLimit_Update` + 最终限幅斜坡 |

输出链路：

1. PV 设定 = min(能量需求, 温度降额上限) → `MpptSetPvPwr`  
2. 逆变有功 = min(|母线限功率|, |温度降额|)  
3. 按电网或油机算连接端有功  
4. 离网时更新电压 RMS 参考  
5. `InvPwrSet_Update` 生成斜坡后的 P/Q  

---

## 6. 子模块详解

### 6.1 `temp_pwr_derate` — 温度降额

- **PV**：约 98~108°C 从 24kW 线性到 0  
- **并网逆变**：逆变温度 103~110°C、控制板 88~105°C，取更严；超停止温度直接 0  
- **离网逆变**：超停止点保留约 1kW；否则降额但不低于 1kW；可通过等效阻抗下调电压参考（约 180~230V）  

### 6.2 `grid_connect_time_ctrl` — 并网时间许可

状态：离网 / 并网中 / 已并网 / 解网中 / 其它  

规则摘要：

- 进入 connecting 记时；超时 `connect_timeout_ms` 禁止  
- 解网中禁止  
- 已并网允许  
- 离网等待 `reconnect_ms` 后允许再连  

注意：`PwrCtrl_Set_DataInput` 当前固定 10 s / 10 s，未必使用通信下发的重连时间。

### 6.3 `drm_pwr_sched` — DRM 功率调度

9 位 DRM 输入：

- 多 bit 同时 → DRM0：输入输出额定 0，继电器许可 0  
- DRM1~4：不同输入能力，输出全额  
- DRM5~7：输入全额，输出 0/50%/75%  
- DRM8 或无 bit：全额  

**当前输出未真正接入限值计算，且 control_state 强制 DRM 许可=1。**

### 6.4 `grid_connect_bus_pwr_limit` — 母线限功率

母线电压四区：

| 区 | 电压带（约） | 行为 |
|----|--------------|------|
| NORMAL | 750~890 V | 透传目标 |
| HOLD | 720~750 或 890~920 | 保持/收紧 |
| PI_CHG | ≥920 | PI 限到 0~16kW |
| PI_DSG | ≤720 | PI 限到 -16~0kW |

流程：10 点滑滤 → 功率转逆变设定 `-(连接端设定+负载)` → 四区 → PI（含限幅与 anti-windup）。

### 6.5 `inv_pwr_set` — 斜坡与限幅

- 对象：逆变、Grid 两套  
- 死区约 50 W  
- 同号变化：死区内直达；超步长按 `max_pwr_slope` 渐变  
- 跨零先回 0，再爬升  
- 非 grid/oil 时复位斜坡；P/Q 按额定钳位

```c
/**
 * @file drm_pwr_sched.c
 * @brief DRM 功率调度
 */

#include "drm_pwr_sched.h"

DrmPwrSched_Output_t gstDrmPwrSchedOut;
/* ========================================================================== */
/*  模块私有函数                                                                  */
/* ========================================================================== */

static void _DrmPwrSched_SetRatedApparentPwr(float32 input_pwr, float32 output_pwr)
{
    gstDrmPwrSchedOut.input_rated_apparent_pwr = input_pwr;
    gstDrmPwrSchedOut.output_rated_apparent_pwr = output_pwr;
}

static DrmPwrSched_State_t _DrmPwrSched_ResolveState(uint16_t drm_state_bits)
{
    uint16_t drm_mask = drm_state_bits & 0x01FFU;
    uint8_t active_count = 0U;
    uint8_t i;
    DrmPwrSched_State_t drm_level = EN_DRM_DRM8;

    if(drm_mask == 0U)
    {
        return EN_DRM_DRM8;
    }

    for(i = 0U; i < 9U; i++)
    {
        if((drm_mask & (0x0001U << i)) != 0U)
        {
            active_count++;
            drm_level = (DrmPwrSched_State_t)i;
        }
    }

    if(active_count >= 2U)
    {
        return EN_DRM_DRM0;
    }

    return drm_level;
}

static void _DrmPwrSched_ApplyLevel(DrmPwrSched_State_t drm_level)
{
    float32 s_in_max = GRID_IN_MAX_APPARENT_PWR_VA;
    float32 s_out_max = GRID_OUT_MAX_APPARENT_PWR_VA;

    switch(drm_level)
    {
    case EN_DRM_DRM0:
        _DrmPwrSched_SetRatedApparentPwr(0.0f, 0.0f);
        break;
    case EN_DRM_DRM1:
        _DrmPwrSched_SetRatedApparentPwr(0.0f, s_out_max);
        break;
    case EN_DRM_DRM2:
        _DrmPwrSched_SetRatedApparentPwr(0.50f * s_in_max, s_out_max);
        break;
    case EN_DRM_DRM3:
        _DrmPwrSched_SetRatedApparentPwr(0.75f * s_in_max, s_out_max);
        break;
    case EN_DRM_DRM4:
        _DrmPwrSched_SetRatedApparentPwr(s_in_max, s_out_max);
        break;
    case EN_DRM_DRM5:
        _DrmPwrSched_SetRatedApparentPwr(s_in_max, 0.0f);
        break;
    case EN_DRM_DRM6:
        _DrmPwrSched_SetRatedApparentPwr(s_in_max, 0.50f * s_out_max);
        break;
    case EN_DRM_DRM7:
        _DrmPwrSched_SetRatedApparentPwr(s_in_max, 0.75f * s_out_max);
        break;
    case EN_DRM_DRM8:
        _DrmPwrSched_SetRatedApparentPwr(s_in_max, s_out_max);
        break;
    default:
        _DrmPwrSched_SetRatedApparentPwr(0.0f, 0.0f);
        break;
    }
    if(drm_level == EN_DRM_DRM0)
    {
        gstDrmPwrSchedOut.drm_relay_control = 0U;
    }
    else
    {
        gstDrmPwrSchedOut.drm_relay_control = 1U;
    }
}

/* ========================================================================== */
/*  对外接口                                                                   */
/* ========================================================================== */

void DrmPwrSched_Init(void)
{
    _DrmPwrSched_SetRatedApparentPwr(GRID_IN_MAX_APPARENT_PWR_VA, GRID_OUT_MAX_APPARENT_PWR_VA);
    gstDrmPwrSchedOut.drm_relay_control = 0U;
}

void DrmPwrSched_Update(void)
{
    DrmPwrSched_State_t drm_level;

    if(gstEnergyManageData.inv_enable == 0U)
    {
        DrmPwrSched_Init();
        return;
    }
    drm_level = _DrmPwrSched_ResolveState(gstEnergyManageData.drm_state_bits);
    _DrmPwrSched_ApplyLevel(drm_level);
}
```

```c
/**
* @brief: 并离网模式下各类限制计算
* @param: on_grid_flag:并离网标志，1表示并网
* @param: p_input:能量调度模块输入信息指针
* @param: p_limit:能量调度模块各端口限制参数指针
* @return: none
* @note:  
*/
static void _OnOffGridLimitCalc(unsigned char on_grid_flag, EnergyCtrlInput_t *p_input, EnergyCtrlLimit_t *p_limit)
{
    /*并网口实时功率限制计算*/
    if(on_grid_flag == 1)//并网模式，非油机模式
    {
        float nload_npcs_total_power = p_input->power_act_ct2grid_get - p_input->power_act_grid2pcs_get;
        float max_ongrid_power;//通过CT流出的最大功率(并到电网的最大功率，正值)

        p_input->power_act_norload_get = nload_npcs_total_power;

        if(p_input->flag_netdisabletest_enable == 1)
        {
            p_input->power_act_norload_get = 0;
        }
        /*并网口流入最大*/
        //先按最大入户功率判断
        p_limit->power_grid2pcs_max_limit = p_input->power_max_household_get - p_input->power_act_norload_get;
        //再按端口限制判断
        if(p_limit->power_grid2pcs_max_limit > GRID_PORT_MAX_POWER)
        {
            p_limit->power_grid2pcs_max_limit = GRID_PORT_MAX_POWER;
        }
        //再按照逆变参数判断
        if(p_limit->power_grid2pcs_max_limit > p_input->power_act_eps_get + PCS_MAX_POWER)
        {
            p_limit->power_grid2pcs_max_limit = p_input->power_act_eps_get + PCS_MAX_POWER;
        }

        /*并网口流出最大*/
        if(p_input->antireverseflow_enable == 1)//防逆流打开
        {
            max_ongrid_power = 0;
        }
        else if(p_input->work_mode == EN_PEAK_VALLEY_MODE && p_input->peak_shift_stat != 2)//削峰填谷非卖电状态
        {
            max_ongrid_power = 0;
        }
        else
        {
            max_ongrid_power = POWER_GET_MIN(p_input->power_max_household_get, p_input->power_max_ongrid_get);
        }
        //先按最大入户功率及最大并网功率判断
        p_limit->power_grid2pcs_min_limit = (0 - max_ongrid_power) - p_input->power_act_norload_get;
        //再按端口限制判断
        if(p_limit->power_grid2pcs_min_limit < (0 - GRID_PORT_MAX_POWER))
        {
            p_limit->power_grid2pcs_min_limit = (0 - GRID_PORT_MAX_POWER);
        }
        //再按照逆变参数判断
        if(p_limit->power_grid2pcs_min_limit < (p_input->power_act_eps_get - PCS_MAX_POWER))
        {
            p_limit->power_grid2pcs_min_limit = (p_input->power_act_eps_get - PCS_MAX_POWER);
        }

        /*油机口输入最大最小*/
        p_limit->power_gen2pcs_max_limit = 0;
        p_limit->power_gen2pcs_min_limit = 0;
    }
    else//离网模式
    {
        /*并网口流入最大和流出最大*/
        p_limit->power_grid2pcs_max_limit = 0;
        p_limit->power_grid2pcs_min_limit = 0;
        /*油机口输入最大最小*/
        if(p_input->work_mode != EN_OIL_MODE)//离网非油机模式
        {
            p_limit->power_gen2pcs_max_limit = 0;
            p_limit->power_gen2pcs_min_limit = 0;//防止因采样误差导致逆流给油机
        }
        else//离网油机模式
        {
            p_limit->power_gen2pcs_max_limit = p_input->power_max_gen_get;
            p_limit->power_gen2pcs_min_limit = 100;//防止因采样误差导致逆流给油机
        }
    }


    /*交流侧流入PCS的最大功率*/
    p_limit->power_inv2pcs_max_limit = p_limit->power_gen2pcs_max_limit + p_limit->power_grid2pcs_max_limit - p_input->power_act_eps_get;
    /*交流侧从PCS流出的最大功率*/
    p_limit->power_inv2pcs_min_limit = p_limit->power_gen2pcs_min_limit + p_limit->power_grid2pcs_min_limit - p_input->power_act_eps_get;

    /*直流侧流入PCS的最大功率*/
    p_limit->power_bus2pcs_max_limit = 0 - p_limit->power_inv2pcs_min_limit;
    /*直流侧从PCS流出的最大功率*/
    p_limit->power_bus2pcs_min_limit = 0 - p_limit->power_inv2pcs_max_limit;

    /*电池最大和最小功率*/
    p_limit->power_bat2bus_max_limit = p_input->power_max_bat_dsg_get;
    p_limit->power_bat2bus_min_limit = 0 - p_input->power_max_bat_chg_get;

    /*EV充电和放电最大功率*/
    if(p_input->ev_mode == 0)//EV给设备充电
    {
        p_limit->power_ev2bus_max_limit = p_limit->power_bus2pcs_max_limit - p_input->power_pv2bus_get - p_limit->power_bat2bus_min_limit;
        if(p_limit->power_ev2bus_max_limit < 0)
        {
            p_limit->power_ev2bus_max_limit = 0;
        }
        if(p_limit->power_ev2bus_max_limit < EV_MAX_POWER)
        {
            p_limit->power_ev2bus_max_limit = EV_MAX_POWER;
        }
        p_limit->power_ev2bus_min_limit = 0;
    }
    else//设备给EV充电
    {
        p_limit->power_ev2bus_max_limit = 0;
        p_limit->power_ev2bus_min_limit = p_limit->power_bus2pcs_min_limit - p_input->power_pv2bus_get - p_limit->power_bat2bus_max_limit;
        if(p_limit->power_ev2bus_min_limit > 0)
        {
            p_limit->power_ev2bus_min_limit = 0;
        }
        if(p_limit->power_ev2bus_min_limit > 0 - EV_MAX_POWER)
        {
            p_limit->power_ev2bus_min_limit = 0 - EV_MAX_POWER;
        }
    }
}



/**
* @brief: 基于电池状态对电池功率的修正
* @param: p_input:能量调度模块输入信息指针
* @param: p_limit:能量调度模块各端口限制参数指针
* @param: p_output:能量调度计算后各模块的功率信息指针
* @return: none
* @note:  
*/
static void _BatPowerLimitConvert(const EnergyCtrlInput_t *p_input,EnergyCtrlLimit_t *p_limit, EnergyCtrlOutput_t *p_output)
{
    if(p_input->power_max_bat_chg_get == 0 && p_input->power_max_bat_dsg_get == 0)//禁充禁放
    {
        p_output->power_bat2bus_set = 0;
    }
    else if(p_input->power_max_bat_chg_get == 0)//禁充
    {
        if(p_output->power_bat2bus_set < 0)
        {
            p_output->power_bat2bus_set = 100;
        }
    }
    else if(p_input->power_max_bat_dsg_get == 0)//禁放
    {
        if(p_output->power_bat2bus_set > 0)
        {
            p_output->power_bat2bus_set = -100;
        }
    }
    p_output->power_bat2bus_set = POWER_VALUE_LIMIT(p_output->power_bat2bus_set, p_limit->power_bat2bus_min_limit, p_limit->power_bat2bus_max_limit);
}


/**
* @brief: 直流母线侧功率限制
* @param: p_input:能量调度模块输入信息指针
* @param: p_limit:能量调度模块各端口限制参数指针
* @param: p_output:能量调度计算后各模块的功率信息指针
* @return: none
* @note:  
*/
static void _DcBusPowerLimit(const EnergyCtrlInput_t *p_input,EnergyCtrlLimit_t *p_limit, EnergyCtrlOutput_t *p_output)
{
    if((p_input->power_pv2bus_get + p_input->power_ev2bus_get) + p_output->power_bat2bus_set > PCS_MAX_POWER)
    {
        p_output->power_bat2bus_set = PCS_MAX_POWER - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);
    }
    else if((p_input->power_pv2bus_get + p_input->power_ev2bus_get) + p_output->power_bat2bus_set < -PCS_MAX_POWER)
    {
        p_output->power_bat2bus_set = -PCS_MAX_POWER - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);
    }
    //再次对电池功率进行限制计算
    _BatPowerLimitConvert(p_input, p_limit, p_output);
}


/**
* @brief: 电池侧功率修正
* @param: origin:修正前的电池功率
* @param: error:上一拍实际电池功率和电池设置功率的差值
* @return: 修正值
* @note:  
*/
static float _BatPowerCorr(float origin, float error)
{
    static float accu_corr_value = 0;//累积修正值
    float res;
#if (ENABLE_BAT_ERROR_CORR == 0)
    accu_corr_value = 0;
#else
    /*方案1*/
    accu_corr_value += error * BAT_ERROR_CORR_FACTOR;
    /*方案2*/
    //accu_corr_value = error;

#endif
    if(accu_corr_value > 2000)
    {
        accu_corr_value = 2000;
    }
    else if(accu_corr_value < -2000)
    {
        accu_corr_value = -2000;
    }
    res = origin - accu_corr_value;

    return res;
}


/**
* @brief: 电池侧功率修正2--仅修正电池功率是否超过界限
* @param: origin:修正前的电池功率
* @param: get:上一拍实际电池功率
* @param: p_limit:能量调度模块各端口限制参数指针
* @return: 修正值
* @note:  
*/
static float _BatPowerCorr2(float origin, float get, EnergyCtrlLimit_t *p_limit)
{
    static float accu_corr_value = 0;//累积修正值
    float res;
#if (ENABLE_BAT_ERROR_CORR == 0)
    accu_corr_value = 0;
#else
    if(get > p_limit->power_bat2bus_max_limit)
    {
        accu_corr_value = (get - p_limit->power_bat2bus_max_limit);
    }
    else if(get < p_limit->power_bat2bus_min_limit)
    {
        accu_corr_value = (get - p_limit->power_bat2bus_min_limit);
    }
    else
    {
        accu_corr_value = 0;
    }
#endif
    res = origin - accu_corr_value;

    return res;
}





/**
* @brief: 并网模式下功率调度计算
* @param: p_input:能量调度模块输入信息指针
* @param: p_limit:能量调度模块各端口限制参数指针
* @param: p_output:能量调度计算后各模块的功率信息指针
* @return: none
* @note:  
*/
static void _OnGridEnergyCtrlCalc(EnergyCtrlInput_t *p_input, EnergyCtrlLimit_t *p_limit, EnergyCtrlOutput_t *p_output)
{
    float correct_grid2pcs_power;//结合限制，应当的并网口功率
    float pv_dist_value = 0;//PV尝试扰动值
    float bat_chg_margin, bat_dsg_margin;//电池充电余量(即电池功率预设值-最小功率限制)和放电余量(最大功率限制-电池功率预设值)，都是正值
    float bat_power_error = p_input->power_bat2bus_get - p_output->power_bat2bus_set;//电池实际功率和预设误差
    float power_bat2bus_set_corr;//修正后的电池功率

    if(p_input->flag_netdisabletest_enable == 1)
    {
        p_input->power_act_norload_get = 0;
    }

    p_output->power_act_gen2pcs_set = 0;
#if ENABLE_DEV_LOSS_POWER == 0
    float power_loss = 0;
#else
    float power_loss = (p_input->power_pv2bus_get + p_input->power_ev2bus_get) + p_input->power_bat2bus_get + p_input->power_act_grid2pcs_get - p_input->power_act_eps_get;//设备损耗功率
#endif
    switch(p_input->work_mode)
    {
        case EN_SPONTANEOUS_USE_MODE://自发自用
        {
            /*自发自用处于并网模式下，光伏和电池共同负责本地负载和远端负载，优先由PV给本地负载和远端负载供电，当PV能量不足时，电池弥补，当电池供电不足时，由电网弥补*/
            float nload_npcs_total_power = p_input->power_act_norload_get;//p_input->power_act_ct2grid_get - p_input->power_act_grid2pcs_get;
            // float total_load_power = p_input->power_act_norload_get + p_input->power_act_eps_get;

            float total_load_power = nload_npcs_total_power + p_input->power_act_eps_get;
            total_load_power = POWER_VALUE_LIMIT(total_load_power, -PCS_MAX_POWER, PCS_MAX_POWER);//这里的总负载功率指的是经过逆变的功率，计算电池功率，所以要用逆变器最大功率限制
            p_output->power_bat2bus_target = total_load_power + power_loss - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);
            // p_output->power_bat2bus_set = total_load_power + power_loss - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);
            break;
        }
        case EN_BAT_PRIORITY_MODE://电池优先
        {
            /*电池优先模式下，光伏和电网共同负责本地负载和远端负载，优先由PV给本地负载和远端负载供电，当PV能量不足时，电网弥补，电网因限制导致不足时，电池弥补(基本不会发生)*/
            p_output->power_bat2bus_target = 0 - p_input->power_max_bat_chg_get;
            // p_output->power_bat2bus_set = 0 - p_input->power_max_bat_chg_get;
            break;
        }
        case EN_PEAK_VALLEY_MODE://削峰填谷
        {
            /*削峰填谷模式，静态模式下，不向电网卖电(能量富余且无需充电则降光伏)，优先由PV给本地负载和远端负载供电，当PV能量不足时，电池弥补，当电池供电不足时，由电网弥补。买电模式下，不向电网卖电(能量富余且无需充电则降光伏)，优先由PV给本地负载和远端负载供电以及电池补电，当PV能量不足时，电网弥补，电网因限制不足时，电池才介入(基本不会发生)。卖电模式下，优先由PV+电池给本地负载和远端负载供电，如能量有富余，则按照不超过最大并网功率输出给电网(满足并网限制前提下电池出全力)*/
            if(p_input->peak_shift_stat == 0)//静态模式，类似自发自用但不并网
            {
                float nload_npcs_total_power = p_input->power_act_norload_get;//p_input->power_act_ct2grid_get - p_input->power_act_grid2pcs_get;
                // float total_load_power = p_input->power_act_norload_get + p_input->power_act_eps_get;
                float total_load_power = nload_npcs_total_power + p_input->power_act_eps_get;
                total_load_power = POWER_VALUE_LIMIT(total_load_power, -PCS_MAX_POWER, PCS_MAX_POWER);//这里的总负载功率指的是经过逆变的功率，计算电池功率，所以要用逆变器最大功率限制
                p_output->power_bat2bus_target = total_load_power + power_loss - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);//不向电网卖电的限制由p_limit->power_grid2pcs_min_limit限制
                // p_output->power_bat2bus_set = total_load_power + power_loss - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);//不向电网卖电的限制由p_limit->power_grid2pcs_min_limit限制
            }
            else if(p_input->peak_shift_stat == 1)//买电模式，类似电池优先
            {
                p_output->power_bat2bus_target = 0 - p_input->power_max_bat_chg_get;//不向电网卖电的限制由p_limit->power_grid2pcs_min_limit限制
                // p_output->power_bat2bus_set = 0 - p_input->power_max_bat_chg_get;//不向电网卖电的限制由p_limit->power_grid2pcs_min_limit限制
            }
            else if(p_input->peak_shift_stat == 2)//卖电模式
            {
                float grid2pcs_min_power = p_limit->power_grid2pcs_min_limit;//卖电情况下并网端口最小值，一般为负值
                p_output->power_bat2bus_target = power_loss + p_input->power_act_eps_get - grid2pcs_min_power - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);
                // p_output->power_bat2bus_set = power_loss + p_input->power_act_eps_get - grid2pcs_min_power - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);
            }
            break;
        }
        default:break;
    }

    // 20260324，新增并网认证测试，电池功率限制
    CertificationTest(p_input, p_output);
    //////////////////////////////////////////////////////////////////////////////////////////////////////////

    _BatPowerLimitConvert(p_input, p_limit, p_output);//结合电池状况，对电池功率进行限制
    //_DcBusPowerLimit(p_input, p_limit, p_output);//结合逆变器状况，对电池功率进行限制
    power_bat2bus_set_corr = _BatPowerCorr(p_output->power_bat2bus_set, bat_power_error);
    //power_bat2bus_set_corr = _BatPowerCorr2(p_output->power_bat2bus_set, p_input->power_bat2bus_get, p_limit);
    bat_chg_margin = p_output->power_bat2bus_set - p_limit->power_bat2bus_min_limit;
    bat_dsg_margin = p_limit->power_bat2bus_max_limit - p_output->power_bat2bus_set;

    p_output->power_act_grid2pcs_set = p_input->power_act_eps_get + power_loss - (p_input->power_pv2bus_get + p_input->power_ev2bus_get) - power_bat2bus_set_corr;

    correct_grid2pcs_power = p_output->power_act_grid2pcs_set;
    correct_grid2pcs_power = POWER_VALUE_LIMIT(correct_grid2pcs_power, p_limit->power_grid2pcs_min_limit, p_limit->power_grid2pcs_max_limit);

    //并网量超过限制(p_output->power_act_grid2pcs_set < correct_grid2pcs_power)，则按照电池限制吸收，如电池不足以吸收，则降光伏(电池吸收后剩余的能量)
    if(correct_grid2pcs_power - p_output->power_act_grid2pcs_set > 0)
    {
        float gen2pcs_diff = correct_grid2pcs_power - p_output->power_act_grid2pcs_set;
        float bat_absorb_power = POWER_GET_MIN(bat_chg_margin, gen2pcs_diff);//电池吸收部分

        p_output->power_act_grid2pcs_set += bat_absorb_power;
        p_output->power_bat2bus_set -= bat_absorb_power;
        if(gen2pcs_diff > bat_chg_margin)//电池不足以吸收,尝试降光伏
        {
            float pv_reduce_power = POWER_GET_MIN(gen2pcs_diff - bat_chg_margin, p_input->power_pv2bus_get);

            p_output->power_pv2bus_set = p_input->power_pv2bus_get - pv_reduce_power;
            p_output->power_act_grid2pcs_set += pv_reduce_power;
        }
    }
    //电网吸收量超过限制(p_output->power_act_grid2pcs_set > correct_grid2pcs_power)，则按照电池限制弥补，如电池不足以弥补，则尝试增加光伏(电池弥补后剩余的能量)
    else if(correct_grid2pcs_power - p_output->power_act_grid2pcs_set < 0)
    {
        float gen2pcs_diff = p_output->power_act_grid2pcs_set - correct_grid2pcs_power;
        float bat_comp_power = POWER_GET_MIN(bat_dsg_margin, gen2pcs_diff);//电池补偿部分

        p_output->power_act_grid2pcs_set -= bat_comp_power;
        p_output->power_bat2bus_set += bat_comp_power;
        if(gen2pcs_diff > bat_dsg_margin)//电池不足以弥补，尝试增加光伏(不在此处增加，通过扰动缓慢增加)
        {
            //p_output->power_pv2bus_set = p_input->power_pv2bus_get + (p_output->power_act_grid2pcs_set - correct_grid2pcs_power - bat_dsg_margin);
        }
    }
    else
    {
        p_output->power_pv2bus_set = p_input->power_pv2bus_get;
    }
    p_output->power_ev2bus_set = p_input->power_ev2bus_get;

    if(p_output->power_pv2bus_set == p_input->power_pv2bus_get)//当期望的光伏等于当前实际值时，可尝试增加光伏
    {
        pv_dist_value = 100;
    }
    p_output->power_pv2bus_set += pv_dist_value;

    /*防止因光伏太大导致设备逆变过载*/
    if((p_output->power_pv2bus_set + p_output->power_ev2bus_set) + p_output->power_bat2bus_set > PCS_MAX_POWER + pv_dist_value + power_loss)
    {
        p_output->power_pv2bus_set = PCS_MAX_POWER - p_output->power_bat2bus_set - p_output->power_ev2bus_set;
    }
    /*光伏不能为负值*/
    if(p_output->power_pv2bus_set < 0)
    {
        p_output->power_pv2bus_set = 0;
    }
    /*光伏不能超过阈值*/
    if(p_output->power_pv2bus_set > PV_MAX_POWER)
    {
        p_output->power_pv2bus_set = PV_MAX_POWER;
    }
}




/**
* @brief: 离网模式下功率调度计算
* @param: p_input:能量调度模块输入信息指针
* @param: p_limit:能量调度模块各端口限制参数指针
* @param: p_output:能量调度计算后各模块的功率信息指针
* @return: none
* @note:  
*/
static void _OffGridEnergyCtrlCalc(EnergyCtrlInput_t *p_input, EnergyCtrlLimit_t *p_limit, EnergyCtrlOutput_t *p_output)
{
    float pv_dist_value = 0;//PV尝试扰动值
    float bat_chg_margin, bat_dsg_margin;
    float bat_power_error = p_input->power_bat2bus_get - p_output->power_bat2bus_set;//电池实际功率和预设误差
    float power_bat2bus_set_corr;//修正后的电池功率
    float power_loss;//设备损耗功率

    p_output->power_act_grid2pcs_set = 0;

    if(p_input->work_mode != EN_OIL_MODE)//离网非油机模式
    {
#if ENABLE_DEV_LOSS_POWER == 1
        power_loss = (p_input->power_pv2bus_get + p_input->power_ev2bus_get) + p_input->power_bat2bus_get - p_input->power_act_eps_get;
#else
        power_loss = 0;
#endif
        p_output->power_bat2bus_set = p_input->power_act_eps_get + power_loss - (p_input->power_pv2bus_get + p_input->power_ev2bus_get);
        _BatPowerLimitConvert(p_input, p_limit, p_output);//结合电池状况，对电池功率进行限制
        power_bat2bus_set_corr = _BatPowerCorr(p_output->power_bat2bus_set, bat_power_error);
        //power_bat2bus_set_corr = _BatPowerCorr2(p_output->power_bat2bus_set, p_input->power_bat2bus_get, p_limit);

        p_output->power_pv2bus_set = p_input->power_pv2bus_get - ((p_input->power_pv2bus_get + p_input->power_ev2bus_get) + power_bat2bus_set_corr - p_input->power_act_eps_get - power_loss);
        p_output->power_ev2bus_set = p_input->power_ev2bus_get;
        p_output->power_act_gen2pcs_set = 0;
    }
    else//离网油机模式
    {
        float correct_gen2pcs_power;//结合限制，应当的油机口功率
#if ENABLE_DEV_LOSS_POWER == 1
        power_loss = (p_input->power_pv2bus_get + p_input->power_ev2bus_get) + p_input->power_bat2bus_get + p_input->power_act_gen2pcs_get - p_input->power_act_eps_get;
#else
        power_loss = 0;
#endif
        p_output->power_bat2bus_set = 0-p_input->power_max_bat_chg_get;
        _BatPowerLimitConvert(p_input, p_limit, p_output);//结合电池状况，对电池功率进行限制
        power_bat2bus_set_corr = _BatPowerCorr(p_output->power_bat2bus_set, bat_power_error);
        //power_bat2bus_set_corr = _BatPowerCorr2(p_output->power_bat2bus_set, p_input->power_bat2bus_get, p_limit);
        bat_chg_margin = p_output->power_bat2bus_set - p_limit->power_bat2bus_min_limit;
        bat_dsg_margin = p_limit->power_bat2bus_max_limit - p_output->power_bat2bus_set;

        p_output->power_act_gen2pcs_set = p_input->power_act_eps_get + power_loss - (p_input->power_pv2bus_get + p_input->power_ev2bus_get) - power_bat2bus_set_corr;
        correct_gen2pcs_power = p_output->power_act_gen2pcs_set;
        correct_gen2pcs_power = POWER_VALUE_LIMIT(correct_gen2pcs_power, p_limit->power_gen2pcs_min_limit, p_limit->power_gen2pcs_max_limit);

        //油机获取功率低于油机下限(p_output->power_act_gen2pcs_set < correct_gen2pcs_power)，则降光伏，油机获取功率高于油机上限(p_output->power_act_gen2pcs_set > correct_gen2pcs_power)，则尝试增加光伏
        if(correct_gen2pcs_power - p_output->power_act_gen2pcs_set > 0)//能量富余
        {
            float gen2pcs_diff = correct_gen2pcs_power - p_output->power_act_gen2pcs_set;
            float bat_absorb_power = POWER_GET_MIN(bat_chg_margin, gen2pcs_diff);//电池吸收部分

            p_output->power_act_gen2pcs_set += bat_absorb_power;
            p_output->power_bat2bus_set -= bat_absorb_power;
            if(gen2pcs_diff > bat_chg_margin)//电池不足以吸收,尝试降光伏
            {
                float pv_reduce_power = POWER_GET_MIN(gen2pcs_diff - bat_chg_margin, p_input->power_pv2bus_get);

                p_output->power_pv2bus_set = p_input->power_pv2bus_get - pv_reduce_power;
                p_output->power_act_gen2pcs_set += pv_reduce_power;
            }
        }
        //p_output->power_pv2bus_set = p_input->power_pv2bus_get - (correct_gen2pcs_power - p_output->power_act_gen2pcs_set);
        //p_output->power_ev2bus_set = p_input->power_ev2bus_get;
        else if(correct_gen2pcs_power - p_output->power_act_gen2pcs_set < 0)//能量不足
        {
            float gen2pcs_diff = p_output->power_act_gen2pcs_set - correct_gen2pcs_power;
            float bat_comp_power = POWER_GET_MIN(bat_dsg_margin, gen2pcs_diff);//电池补偿部分

            p_output->power_act_gen2pcs_set -= bat_comp_power;
            p_output->power_bat2bus_set += bat_comp_power;
            if(gen2pcs_diff > bat_dsg_margin)//电池不足以弥补，尝试增加光伏(不在此处增加，通过扰动缓慢增加)
            {
                //p_output->power_pv2bus_set = p_input->power_pv2bus_get + (p_output->power_act_gen2pcs_set - correct_gen2pcs_power - bat_dsg_margin);
            }
        }
        else
        {
            p_output->power_pv2bus_set = p_input->power_pv2bus_get;
        }
        p_output->power_ev2bus_set = p_input->power_ev2bus_get;
        //油机不允许瞬间过冲，需要直接按照限制配置
        //p_output->power_bat2bus_set += (p_output->power_act_gen2pcs_set - correct_gen2pcs_power);
        //p_output->power_act_gen2pcs_set = correct_gen2pcs_power;
    }

    if(p_output->power_pv2bus_set == p_input->power_pv2bus_get)//当期望的光伏等于当前实际值时，可尝试增加光伏
    {
        pv_dist_value = 100;
    }
    p_output->power_pv2bus_set += pv_dist_value;

    /*防止因光伏太大导致设备逆变过载*/
    if((p_output->power_pv2bus_set + p_output->power_ev2bus_set) + p_output->power_bat2bus_set > PCS_MAX_POWER + pv_dist_value + power_loss)
    {
        p_output->power_pv2bus_set = PCS_MAX_POWER - p_output->power_bat2bus_set - p_output->power_ev2bus_set;
    }
    /*光伏不能为负值*/
    if(p_output->power_pv2bus_set < 0)
    {
        p_output->power_pv2bus_set = 0;
    }
    /*光伏不能超过阈值*/
    if(p_output->power_pv2bus_set > PV_MAX_POWER)
    {
        p_output->power_pv2bus_set = PV_MAX_POWER;
    }
}
```

```c
#include "grid_connect_bus_pwr_limit.h"
#include "mid_sliding_filter.h"

typedef struct grid_bus_pwr_ctrl_stru_t

/* ========================================================================== */
/*  模块私有函数                                                               */
/* ========================================================================== */

static float32 _GridBusPwrLimit_InvPwrSet(float32 active_pwr_set, float32 load_active_pwr)
{
    return -1.0f * (active_pwr_set + load_active_pwr);
}

static float32 _GridBusPwrLimit_ClampInvPwr(float32 inv_pwr_set, float32 max_pwr, float32 min_pwr)
{
    if(inv_pwr_set > max_pwr)
    {
        return max_pwr;
    }
    if(inv_pwr_set < min_pwr)
    {
        return min_pwr;
    }
    return inv_pwr_set;
}

static void _GridBusPwrCtrl_Init(void)
{
    _gPwrCtrl.busvol_protect_upper = GRID_BUS_PWR_LIMIT_PROTECT_UPPER_V;
    _gPwrCtrl.busvol_protect_lower = GRID_BUS_PWR_LIMIT_PROTECT_LOWER_V;
    _gPwrCtrl.busvol_theory_upper = GRID_BUS_PWR_LIMIT_THEORY_UPPER_V;
    _gPwrCtrl.busvol_theory_lower = GRID_BUS_PWR_LIMIT_THEORY_LOWER_V;
    _gPwrCtrl.kp = GRID_BUS_PWR_LIMIT_KP;
    _gPwrCtrl.ki = GRID_BUS_PWR_LIMIT_KI;
    _gPwrCtrl.integral = 0.0f;
    _gPwrCtrl.bus_vol_error = 0.0f;
    _gPwrCtrl.pwr_out = 0.0f;
    _gPwrCtrl.ctrl_mode = EN_GRID_BUS_PWR_CTRL_NORMAL;
}

static void _GridBusPwrLimit_ResetRuntime(void)
{
    Mid_SlidingFilter_Init(&_gBusVoltFilter,
                           _gBusVoltFilterBuf,
                           (uint16_t)GRID_BUS_VOLT_FILTER_WIN_SIZE);
    _GridBusPwrCtrl_Init();
}

static void _GridBusPwrCtrl_ModeSelect(GridBusPwrCtrl_t* p_ctrl, float32 filtered_voltage)
{
    if((filtered_voltage > p_ctrl->busvol_theory_lower)
       && (filtered_voltage < p_ctrl->busvol_theory_upper))
    {
        p_ctrl->ctrl_mode = EN_GRID_BUS_PWR_CTRL_NORMAL;
    }
    else if(((filtered_voltage > p_ctrl->busvol_theory_upper)
              && (filtered_voltage < p_ctrl->busvol_protect_upper))
             || ((filtered_voltage < p_ctrl->busvol_theory_lower)
                 && (filtered_voltage > p_ctrl->busvol_protect_lower)))
    {
        p_ctrl->ctrl_mode = EN_GRID_BUS_PWR_CTRL_HOLD;
    }
    else if(filtered_voltage >= p_ctrl->busvol_protect_upper)
    {
        p_ctrl->ctrl_mode = EN_GRID_BUS_PWR_CTRL_PI_CHG;
    }
    else if(filtered_voltage <= p_ctrl->busvol_protect_lower)
    {
        p_ctrl->ctrl_mode = EN_GRID_BUS_PWR_CTRL_PI_DSG;
    }
    else
    {
        p_ctrl->ctrl_mode = EN_GRID_BUS_PWR_CTRL_HOLD;
    }
}

static void _GridBusPwrCtrl_HoldRun(GridBusPwrCtrl_t* p_ctrl, float32 inv_pwr_set)
{
    float32 out = p_ctrl->pwr_out;

    if((out > 0.0f) && (inv_pwr_set > 0.0f))
    {
        out = (out < inv_pwr_set) ? out : inv_pwr_set;
    }
    else if((out < 0.0f) && (inv_pwr_set < 0.0f))
    {
        out = (out > inv_pwr_set) ? out : inv_pwr_set;
    }
    else
    {
        out = inv_pwr_set;
    }

    p_ctrl->pwr_out = out;
    p_ctrl->integral = 0.0f;
}

static void _GridBusPwrCtrl_PiChgRun(GridBusPwrCtrl_t* p_ctrl, float32 filtered_voltage, float32 dt_s)
{
    float32 out;

    p_ctrl->bus_vol_error = p_ctrl->busvol_protect_upper - filtered_voltage;
    p_ctrl->integral += p_ctrl->bus_vol_error * dt_s;
    out = p_ctrl->pwr_out + p_ctrl->kp * p_ctrl->bus_vol_error + p_ctrl->ki * p_ctrl->integral;

    if(out > GRID_BUS_PWR_LIMIT_GRID_PWR_MAX_W)
    {
        out = GRID_BUS_PWR_LIMIT_GRID_PWR_MAX_W;
        if(p_ctrl->bus_vol_error < 0.0f)
        {
            p_ctrl->integral = 0.0f;
        }
    }
    else if(out < 0.0f)
    {
        out = 0.0f;
        if(p_ctrl->bus_vol_error < 0.0f)
        {
            p_ctrl->integral = 0.0f;
        }
    }

    p_ctrl->pwr_out = out;
}

static void _GridBusPwrCtrl_PiDsgRun(GridBusPwrCtrl_t* p_ctrl, float32 filtered_voltage, float32 dt_s)
{
    float32 out;

    p_ctrl->bus_vol_error = p_ctrl->busvol_protect_lower - filtered_voltage;
    p_ctrl->integral += p_ctrl->bus_vol_error * dt_s;
    out = p_ctrl->pwr_out + p_ctrl->kp * p_ctrl->bus_vol_error + p_ctrl->ki * p_ctrl->integral;

    if(out > 0.0f)
    {
        out = 0.0f;
        if(p_ctrl->bus_vol_error > 0.0f)
        {
            p_ctrl->integral = 0.0f;
        }
    }
    else if(out < GRID_BUS_PWR_LIMIT_INV_PWR_MIN_W)
    {
        out = GRID_BUS_PWR_LIMIT_INV_PWR_MIN_W;
        if(p_ctrl->bus_vol_error > 0.0f)
        {
            p_ctrl->integral = 0.0f;
        }
    }

    p_ctrl->pwr_out = out;
}

static void _GridBusPwrLimit_Calc(GridBusPwrCtrl_t* p_ctrl,
                                  float32 filtered_voltage,
                                  float32 inv_pwr_set,
                                  float32 dt_s)
{
    _GridBusPwrCtrl_ModeSelect(p_ctrl, filtered_voltage);

    switch(p_ctrl->ctrl_mode)
    {
    case EN_GRID_BUS_PWR_CTRL_NORMAL:
        p_ctrl->pwr_out = inv_pwr_set;
        p_ctrl->integral = 0.0f;
        break;

    case EN_GRID_BUS_PWR_CTRL_HOLD:
        _GridBusPwrCtrl_HoldRun(p_ctrl, inv_pwr_set);
        break;

    case EN_GRID_BUS_PWR_CTRL_PI_CHG:
        _GridBusPwrCtrl_PiChgRun(p_ctrl, filtered_voltage, dt_s);
        break;

    case EN_GRID_BUS_PWR_CTRL_PI_DSG:
        _GridBusPwrCtrl_PiDsgRun(p_ctrl, filtered_voltage, dt_s);
        break;

    default:
        p_ctrl->pwr_out = inv_pwr_set;
        break;
    }
}

float32 GridBusPwrLimit_GridPwr(float32 inv_pwr, float32 load_active_pwr)
{
    return (-inv_pwr) - load_active_pwr;
}

void GridBusPwrLimit_Init(void)
{
    _GridBusPwrLimit_ResetRuntime();
    gstGridBusPwrLimitOut.inv_pwr_limited = 0.0f;
}   

void GridBusPwrLimit_Update(float32 bus_pwr_derate_in)
{
    float32 filtered_voltage;
    float32 pwr_set;

    if((gstEnergyManageData.grid_enable == 0U && gstEnergyManageData.oil_enable == 0U) || gstEnergyManageData.inv_enable == 0U)
    {
        _GridBusPwrLimit_ResetRuntime();
        gstGridBusPwrLimitOut.inv_pwr_limited = 0.0f;
        return;
    }
    pwr_set = _GridBusPwrLimit_InvPwrSet(bus_pwr_derate_in, gstEnergyManageData.load_total_active_pwr);
    pwr_set = _GridBusPwrLimit_ClampInvPwr(pwr_set, GRID_BUS_PWR_LIMIT_GRID_PWR_MAX_W, GRID_BUS_PWR_LIMIT_INV_PWR_MIN_W);

    filtered_voltage = Mid_SlidingFilter_Update(&_gBusVoltFilter, gstEnergyManageData.bus_voltage);
    _GridBusPwrLimit_Calc(&_gPwrCtrl, filtered_voltage, pwr_set, GRID_BUS_PWR_LIMIT_CTRL_DT_S);

//    gstGridBusPwrLimitOut.inv_pwr_limited = GridBusPwrLimit_GridPwr(_gPwrCtrl.pwr_out, gstEnergyManageData.load_total_active_pwr);

    gstGridBusPwrLimitOut.inv_pwr_limited = _GridBusPwrLimit_ClampInvPwr(_gPwrCtrl.pwr_out, GRID_BUS_PWR_LIMIT_GRID_PWR_MAX_W, GRID_BUS_PWR_LIMIT_INV_PWR_MIN_W);
}
```

```c
    gstGridConnectTimeCtrlOut.grid_enable = 0U;

{
    uint16_t grid_enable = 0U;
    uint32_t now_ms;

    now_ms = gstEnergyManageData.now_ms;

    if((gstEnergyManageData.inv_run_state == GRID_CONNECT_TIME_INV_CONNECTING)
       && (_gLastInvRunState != GRID_CONNECT_TIME_INV_CONNECTING))
    {
        _gConnectMs = now_ms;
    }
    if((gstEnergyManageData.inv_run_state == GRID_CONNECT_TIME_INV_DISCONNECTING)
       && (_gLastInvRunState != GRID_CONNECT_TIME_INV_DISCONNECTING))
    {
        _gCooldownMs = now_ms;
    }

    if(gstEnergyManageData.inv_run_state == GRID_CONNECT_TIME_INV_ON_GRID)
    {
        grid_enable = 1U;
        _gCooldownMs = now_ms;
    }
    else if(gstEnergyManageData.inv_run_state == GRID_CONNECT_TIME_INV_DISCONNECTING)
    {
        grid_enable = 0U;
    }
    else if(gstEnergyManageData.inv_run_state == GRID_CONNECT_TIME_INV_CONNECTING)
    {
        grid_enable = (TimDifftime(_gConnectMs, now_ms) <= gstEnergyManageData.connect_timeout_ms)
                          ? 1U
                          : 0U;
        if(grid_enable == 0U)
        {
            _gCooldownMs = now_ms;
        }
    }
    else if(gstEnergyManageData.inv_run_state == GRID_CONNECT_TIME_INV_OFFGRID)
    {
        if(TimDifftime(_gCooldownMs, now_ms) > gstEnergyManageData.reconnect_ms)
        {
            grid_enable = 1U;
            _gConnectMs = now_ms;
        }
    }

    _gLastInvRunState = gstEnergyManageData.inv_run_state;
    gstGridConnectTimeCtrlOut.grid_enable = grid_enable;
}
```

```c
static float32 _InvPwrSet_PowerRampUpdate(float32 current, float32 max_slope, float32 target)
{
    float32 delta = fabsf(target) - fabsf(current);

    if(((current >= 0.0f) && (target >= 0.0f)) || ((current <= 0.0f) && (target <= 0.0f)))
    {
        if(fabsf(delta) <= INV_PWR_SET_RAMP_DEADBAND_W)
        {
            return target;
        }
        if(fabsf(delta) <= max_slope)
        {
            return target;
            }
        if(delta > 0.0f)
        {
            return current + ((target > 0.0f) ? max_slope : -max_slope);
        }
        return target;
    }

    return 0.0f;
}

static void _InvPwrSet_ClampPwr(float32 active_pwr,
                                float32 reactive_pwr,
                                float32 p_min_limit,
                                float32 p_max_limit,
                                float32 q_min_limit,
                                float32 q_max_limit,
                                InvPwrSet_Output_t* p_output)
{
    if(active_pwr >= p_max_limit)
    {
        active_pwr = p_max_limit;
    }
    else if(active_pwr <= p_min_limit)
    {
        active_pwr = p_min_limit;
    }

    if(reactive_pwr >= q_max_limit)
    {
        reactive_pwr = q_max_limit;
    }
    else if(reactive_pwr <= q_min_limit)
    {
        reactive_pwr = q_min_limit;
    }

    p_output->p_power = active_pwr;
    p_output->q_power = reactive_pwr;
}

static void _PwrSet_RampUpdate(InvPwrSet_Ctrl_t *pwr_set,float32 active_pwr, float32 reactive_pwr)
{
    pwr_set->ramp_p = _InvPwrSet_PowerRampUpdate(pwr_set->ramp_p,
                                                     gstEnergyManageData.max_pwr_slope,
                                                     active_pwr);
    pwr_set->ramp_q = _InvPwrSet_PowerRampUpdate(pwr_set->ramp_q,
                                                     gstEnergyManageData.max_pwr_slope,
                                                     reactive_pwr);
}

    _InvPwrSet_ClampPwr(_gInvPwrSet.ramp_p,
                         _gInvPwrSet.ramp_q,
```

```c
void EnergyScheduling(void)
{
    static uint16_t sched_cht_div = 0;
    float32 bus_pwr_derate_in = 0;
    float32 inv_abs_pwr = 0;
    float32 pv_pwr_set = 0;
    float32 inv_active_pwr_sign = 1;
    float32 inv_active_pwr_set = 0 ;
    float32 connect_active_set = 0;

    sched_cht_div ++;
    if(sched_cht_div % 10 == 0)
    {
        EnergyManage_Run(&gstEnergyCtrlInputData);
//        gstEnergyManagePwrOut.gen_pwr
//        gstEnergyManagePwrOut.grid_active_pwr
//        gstEnergyManagePwrOut.pv_pwr
    }
    if(sched_cht_div % 15 == 0)
    {
        GridConnectTimeCtrl_Update();
    }
    if(sched_cht_div % 20 == 0)
    {
        TempPwrDerate_Update();
//        gstTempPwrDerateOut.pv_pwr
//        gstTempPwrDerateOut.inv_active_pwr
//        gstTempPwrDerateOut.disconnect_volt_ref

        DrmPwrSched_Update();
//        gstDrmPwrSchedOut.input_rated_apparent_pwr
//        gstDrmPwrSchedOut.output_rated_apparent_pwr
    }

    if(gstEnergyManageData.inv_enable && gstEnergyManageData.grid_enable)

        bus_pwr_derate_in = gstEnergyManagePwrOut.grid_active_pwr;
    }
    else if(gstEnergyManageData.inv_enable && gstEnergyManageData.oil_enable)
    {
        bus_pwr_derate_in = gstEnergyManagePwrOut.gen_pwr;
    }
    GridBusPwrLimit_Update(bus_pwr_derate_in);                  //母线降额运行
    /*******************************PV功率设置***********************************/
    if(gstEnergyManagePwrOut.pv_pwr >= gstTempPwrDerateOut.pv_pwr)
    {
        pv_pwr_set = gstTempPwrDerateOut.pv_pwr;
    }
    else
    {
        pv_pwr_set = gstEnergyManagePwrOut.pv_pwr;
    }
    pv_pwr_set = POWER_VALUE_LIMIT(pv_pwr_set,0,PV_MAX_PWR_W);

    if(sched_cht_div % 20 == 0)
    {
        MpptSetPvPwr(pv_pwr_set);
    }
    gstPwrCtrlInterface.pv_pwr = pv_pwr_set;
    /*******************************逆变功率设置***********************************/
    if(fabsf(gstGridBusPwrLimitOut.inv_pwr_limited) >= fabsf(gstTempPwrDerateOut.inv_active_pwr))

        inv_abs_pwr = fabsf(gstTempPwrDerateOut.inv_active_pwr);

        connect_active_set = POWER_VALUE_LIMIT(connect_active_set,0,OIL_MAX_ACTIVE_PWR_W);

    gstPwrCtrlInterface.connect_reactive_pwr = 0;

    if(sched_cht_div % 20 == 0)

        gstPwrCtrlInterface.off_grid_inv_ref = gstTempPwrDerateOut.disconnect_volt_ref;

    /**********************************逆变及电网功率斜坡给定***********************************/
    InvPwrSet_Update(gstPwrCtrlInterface.inv_active_pwr,gstPwrCtrlInterface.inv_reactive_pwr ,\

                POWER_VALUE_LIMIT(gstGridPwrSetOut.p_power,-GRID_OUT_MAX_ACTIVE_PWR_W,GRID_IN_MAX_ACTIVE_PWR_W);
```

```c
 * @brief 温度降额：光伏 / 逆变 / 控制板功率限制
 */

#include "temp_pwr_derate.h"
#include <math.h>

TempPwrDerate_Output_t gstTempPwrDerateOut;

/* ========================================================================== */
/*  模块私有变量                                                               */
/* ========================================================================== */

static float32 _gPvTempFilt;
static float32 _gInvTempFilt;
static float32 _gCtrTempFilt;

/* ========================================================================== */
/*  模块私有函数                                                               */

static float32 _TempPwrDerate_LinearDerateHighTemp(float32 temp,
                                                   float32 t_start,
                                                   float32 t_stop,
                                                   float32 max_pwr)
{
    float32 slope;
    float32 diff;

    if(temp > t_stop)
    {
        return 0.0f;
    }
    if(temp <= t_start)
    {
        return max_pwr;
    }

    slope = max_pwr / (t_stop - t_start);
    diff = temp - t_start;
    return max_pwr - diff * slope;
}

static float32 _TempPwrDerate_PvTempPwrDerate(float32 pv_temp)
{
    float32 pv_pwr;

    pv_pwr = _TempPwrDerate_LinearDerateHighTemp(pv_temp,
                                                 TEMP_PWR_DERATE_PV_TEMP_START,
                                                 TEMP_PWR_DERATE_PV_TEMP_STOP,
                                                 PV_MAX_PWR_W);
    if(pv_pwr < 0.0f)
    {
        pv_pwr = 0.0f;
    }

    return pv_pwr;
}

static float32 _TempPwrDerate_InvCtrTempPwrDerate(float32 inv_temp,
                                                  float32 ctr_temp,
                                                  float32 max_pwr)
{
    float32 inv_pwr = max_pwr;
    float32 ctr_pwr = max_pwr;
    uint16_t inv_limited = 0U;
    uint16_t ctr_limited = 0U;

    if(inv_temp > TEMP_PWR_DERATE_INV_TEMP_START && inv_temp <= TEMP_PWR_DERATE_INV_TEMP_STOP)
    {
        inv_pwr = _TempPwrDerate_LinearDerateHighTemp(inv_temp,
                                                      TEMP_PWR_DERATE_INV_TEMP_START,
                                                      TEMP_PWR_DERATE_INV_TEMP_STOP,
                                                      max_pwr);
        inv_limited = 1U;
    }

    if(ctr_temp > TEMP_PWR_DERATE_CTR_TEMP_START && ctr_temp <= TEMP_PWR_DERATE_CTR_TEMP_STOP)
    {
        ctr_pwr = _TempPwrDerate_LinearDerateHighTemp(ctr_temp,
                                                      TEMP_PWR_DERATE_CTR_TEMP_START,
                                                      TEMP_PWR_DERATE_CTR_TEMP_STOP,
                                                      max_pwr);
        ctr_limited = 1U;
    }

    if(inv_limited != 0U && ctr_limited != 0U)
    {
        return (inv_pwr < ctr_pwr) ? inv_pwr : ctr_pwr;
    }
    if(inv_limited != 0U)
    {
        return inv_pwr;
    }
    if(ctr_limited != 0U)
    {
        return ctr_pwr;
    }

    return max_pwr;
}

static float32 _TempPwrDerate_OffGridVoltFromTempPwrDerate(float32 pwr_derate,
                                                           float32 volt_rms_ref,
                                                           float32 load_total_active_pwr)
{
    float32 vol_rms = (volt_rms_ref > 0.0f) ? volt_rms_ref : INV_RATED_VOLT_RMS_V;
    float32 single_pwr_ref = pwr_derate / TEMP_PWR_DERATE_PHASE_NUM;
    float32 single_pwr_act = load_total_active_pwr / TEMP_PWR_DERATE_PHASE_NUM;
    float32 actual_resister;
    float32 vol_rms_out;

    if(single_pwr_act < 0.0f)
    {
        single_pwr_act = -single_pwr_act;
    }
    if(single_pwr_act < 1.0f)
    {
        single_pwr_act = 1.0f;
    }

    actual_resister = (vol_rms * vol_rms) / single_pwr_act;
    vol_rms_out = sqrtf(single_pwr_ref * actual_resister);
    if(vol_rms_out < INV_MIN_VOLT_RMS_V)
    {
        vol_rms_out = INV_MIN_VOLT_RMS_V;
    }
    if(vol_rms_out > INV_RATED_VOLT_RMS_V)
    {
        vol_rms_out = INV_RATED_VOLT_RMS_V;
    }
    return vol_rms_out;
}

static float32 _TempPwrDerate_ClampF32(float32 val, float32 min_val, float32 max_val)
{
    if(val > max_val)
    {
        return max_val;
    }
    if(val < min_val)
    {
        return min_val;
    }
    return val;
}

static void _TempPwrDerate_ClampOutput(TempPwrDerate_Output_t* p_output)
{
    p_output->pv_pwr = _TempPwrDerate_ClampF32(p_output->pv_pwr,
                                               0,
                                               TEMP_PWR_DERATE_PV_PWR_MAX_W);

    p_output->inv_active_pwr = _TempPwrDerate_ClampF32(p_output->inv_active_pwr,
                                                       0,
                                                       TEMP_PWR_DERATE_INV_PWR_GRID_MAX_W);
    if(gstEnergyManageData.inv_enable == 1U && gstEnergyManageData.grid_enable == 0U &&\
        gstEnergyManageData.oil_enable == 0U)
    {
        p_output->disconnect_volt_ref =
            _TempPwrDerate_ClampF32(p_output->disconnect_volt_ref,
                                    TEMP_PWR_DERATE_DISCONNECT_VOLT_MIN_V,
                                    TEMP_PWR_DERATE_DISCONNECT_VOLT_MAX_V);
    }
}

static void _TempPwrDerate_InvOffGrid(float32 inv_temp,
                                      float32 ctr_temp,
                                      TempPwrDerate_Output_t* p_output)
{
    float32 inv_pwr;
    float32 volt_ref;

    if(inv_temp > TEMP_PWR_DERATE_INV_TEMP_STOP || ctr_temp > TEMP_PWR_DERATE_CTR_TEMP_STOP)
    {
        inv_pwr = TEMP_PWR_DERATE_INV_DISCONNECT_MIN_PWR;
    }
    else
    {
        inv_pwr = _TempPwrDerate_InvCtrTempPwrDerate(inv_temp,
                                                     ctr_temp,
                                                     INV_OFFGRID_MAX_ACTIVE_PWR_W);
        if(inv_pwr < TEMP_PWR_DERATE_INV_DISCONNECT_MIN_PWR)
        {
            inv_pwr = TEMP_PWR_DERATE_INV_DISCONNECT_MIN_PWR;
        }
    }

    p_output->inv_active_pwr = inv_pwr;

    if((inv_temp <= TEMP_PWR_DERATE_INV_TEMP_START)
       && (ctr_temp <= TEMP_PWR_DERATE_CTR_TEMP_START))
    {
        volt_ref = TEMP_PWR_DERATE_DISCONNECT_VOLT_RMS_V;
    }
    else
    {
        volt_ref = _TempPwrDerate_OffGridVoltFromTempPwrDerate(inv_pwr,
                                                               gstEnergyManageData.inv_volt_rms,
                                                               gstEnergyManageData.load_total_active_pwr);
    }

    p_output->disconnect_volt_ref = volt_ref;
}

static void _TempPwrDerate_InvGridConnected(float32 inv_temp,
                                            float32 ctr_temp,
                                            TempPwrDerate_Output_t* p_output)
{
    float32 inv_pwr;

    if(inv_temp > TEMP_PWR_DERATE_INV_TEMP_STOP || ctr_temp > TEMP_PWR_DERATE_CTR_TEMP_STOP)
    {
        p_output->inv_active_pwr = 0.0f;
        return;
    }

    inv_pwr = _TempPwrDerate_InvCtrTempPwrDerate(inv_temp,
                                                 ctr_temp,
                                                 INV_ON_GRID_MAX_ACTIVE_PWR_W);
    if(inv_pwr < 0.0f)
    {
        inv_pwr = 0.0f;
    }

    p_output->inv_active_pwr = inv_pwr;
}

    gstTempPwrDerateOut.inv_active_pwr = INV_ON_GRID_MAX_ACTIVE_PWR_W;

{
    if(gstEnergyManageData.inv_enable == 0U )
    {   
        gstTempPwrDerateOut.pv_pwr = 0.0f;
        gstTempPwrDerateOut.inv_active_pwr = 0.0f;
        gstTempPwrDerateOut.disconnect_volt_ref = TEMP_PWR_DERATE_DISCONNECT_VOLT_RMS_V;
        return;
    }

    _gPvTempFilt = gstEnergyManageData.pv_temp;
    _gInvTempFilt = gstEnergyManageData.inv_temp;
    _gCtrTempFilt = gstEnergyManageData.ctr_temp;
    gstTempPwrDerateOut.pv_pwr = _TempPwrDerate_PvTempPwrDerate(_gPvTempFilt);
    gstTempPwrDerateOut.inv_active_pwr = 0.0f;
    gstTempPwrDerateOut.disconnect_volt_ref = TEMP_PWR_DERATE_DISCONNECT_VOLT_RMS_V;

    if(gstEnergyManageData.grid_enable  ||  gstEnergyManageData.oil_enable )
    {
        _TempPwrDerate_InvGridConnected(_gInvTempFilt, _gCtrTempFilt, &gstTempPwrDerateOut);
    }
    else 
    {
        _TempPwrDerate_InvOffGrid(_gInvTempFilt, _gCtrTempFilt, &gstTempPwrDerateOut);
    }

    _TempPwrDerate_ClampOutput(&gstTempPwrDerateOut);
}
```
