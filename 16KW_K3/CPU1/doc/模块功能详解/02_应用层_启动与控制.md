# 02 应用层：启动与控制

对应源码：`app/main.c`、`app/cpu_control.*`、`app/control_state.*`、`app/algo_interface.*`

---

## 1. `main.c` — 启动入口与前台调度

### 1.1 职责

CPU1 唯一入口：规定硬件初始化顺序、引导 CPU2、开启全局中断、进入永久主循环。

### 1.2 启动顺序（逐步）

1. `InitSysCtrl()` → 延时 500 ms → `DINT`  
2. `InitFlash` / 清 `IER`/`IFR` / `InitPieCtrl` / `InitPieVectTable`  
3. `DualCore_InitEarly()`：仅配置 CPUSEL 与 GS 归属  
4. `CpuIntFunInit()`：注册 80 kHz ISR  
5. 外设：`FanInit` → `EPwm_Init` → `Cap_Init` → `Gpio_Init` → `Sci_Init` → `Spi_Init` → `AdcConfig` → `CpuTimer_Init` → `CanInit` → `DevLedInit` → `FlashInit`  
6. `ProtocolInit()`：通信协议栈  
7. `ClearEpwmTZ()`：清除 PWM Trip  
8. 算法与业务：`Pv_Init` → `AlgoInterfaceInit` → `Inv3Ph_Init` → `NTCInit` → `RelayControlInit` → `ErrWarningCheckInit` → `BizFsm_Interface_Init` → `PwrCtrlInterface_Init` → `ControlStateInit`  
9. 引导 CPU2：Boot → Handshake → `Ph3CalcInfo_Init` → `DualDataShare_Init` → `DevDcr_ExchangeAddress`；失败则 `DualCore_SetCpu2PowerOnOnline(false)`  
10. `DualDataShare_UpdatePh3Cmd`、`Ph3StsInfo_Init`、励磁继电器 ON、STS 运行使能  
11. `EINT`/`ERTM`，进入 `for(;;)`

### 1.3 主循环（详见 01 文档）

每圈必跑：`ProtocolProcess`、`CpuTimerFlag`、`DevLedProcess`、`BackUpSwitchCtrlFunc`。  
周期任务：1/5/10/20/100/500/1000 ms 标志消费。

### 1.4 重要缺口（实现现状）

当前 `main.c` **未调用**：

- `SysSelfTestInit()` / 直接调度 POST（自检由 BizFSM 状态内触发，但 Init 依赖零初值）
- `Init_System_Parameter()`（Flash 持有参数开机加载）

量产前需确认这两处是否由其他路径补齐。

## 2. `cpu_control` — 80 kHz ISR 调度

### 2.1 职责

把硬件 EPWM7 中断拆成「采样 → MUX 切换 → 时隙任务 → 耗时统计」。

### 2.2 关键变量

| 符号 | 含义 |
|------|------|
| `gstCpuInterrupt.time` | 当前时隙 |
| `gCpuAdcSampleTimeSlot` | 调试用当前时隙 |
| `gCpuTimeSlotHitCnt[5]` | 各时隙命中次数 |
| `_gInterruptRunCont` | 本轮 ISR 耗时（Timer1 tick） |
| `gDutyPv[4]` | PV 占空比预留 |

### 2.3 `CpuIntServiceFun()` 步骤

1. 记录 Timer1 起始值  
2. 保存时隙、递增命中计数  
3. `GetAdcResult(time)`  
4. `AdcGpioStateSwitch()` 切下一 MUX  
5. `Cpu_Interrupt_Process()`  
6. 计算 ISR 运行时间

### 2.4 `Cpu_Interrupt_Process()` 时隙任务

- **TIME1**：`Ph3CalcInfo_Update()`；IPC 触发 CPU2；心跳判在线  
- **TIME2**：`Inv_State_Int1()`；`SciaRxDataRecv()`（协处理器）  
- **TIME3**：`Inv3Ph_FaultFastCheck_Run()`；`ScicRxDataRecv()`（电表）  
- **TIME4**：`ScibRxDataRecv()`（ARC）

### 2.5 SCI 口映射（头文件内联）

| 物理口 | 逻辑 COM | 用途 |
|--------|----------|------|
| SCIB | `COM_INDEX0` | ARC RS485 |
| SCIC | `COM_INDEX1` | 电表 |
| SCIA | `COM_INDEX2` | 协处理器 MCU |

接收路径：ISR 内读 FIFO 一字节 → `mid_comservice_data_in()`。

### 2.6 MUX 切换与快保护入口

`AdcGpioStateSwitch()` 按 `1→2→3→4→1` 切 GPIO34/35/40/41；  
在 TIME3→TIME4 过渡时调用 `FastErrWarningHandler()`。

## 3. `control_state` — 运行许可合成

### 3.1 职责

把监控开关、业务 FSM、母线、CPU2、STS、相序、继电器等多源条件，合成为 **逆变/PV 最终许可**，并在 ISR 与 1 ms 任务中分别更新快/慢路径。

### 3.2 关键结构 `ActionPermit_t`

- 母线许可、监控许可、内部故障许可  
- CPU2 在线许可、STS 状态许可  
- 并网时间 / DRM / 相序 / 强制油机等许可  

对外 PCS 状态枚举 `EN_INV_STATE`：待机、自检、离网、并网中、并网、解网中（区分电网/油机）。

### 3.3 核心私有函数逻辑

#### `_PvWorkPermit_Bus` / `_InvWorkPermit_Bus`

母线正常需 **连续 7 次** 才恢复许可（防抖）。

#### `_InvWorkPermit_Monitor`

- `allow_offgrid && allow_grid_connect` → 可并网  
- 仅 `allow_offgrid` → 可离网运行  

许可来自 Biz FSM 的 `BizFsm_ExtAllow_t`。

#### `_WorkPermit_Cpu2`

要求 CPU2「上电在线」且「运行在线」。

#### `_WorkPermit_ConectDelayChk`

STS 进入 connected 后累计 **500 次** 才给 VF→PQ 的 `connect_run` 许可。

#### `_GridAndGenPhaseJudge`

仅当 STS 断开时，用 CPU2 三相相位+RMS 调 `Sts_PhaseSeq_Analyze()`，更新网/油机相序许可。

#### `_GridAndGenRelagControl`

按 STS 油机模式、继电器请求与故障状态控制 Grid/Gen 继电器。

#### `_InvWorkRunControl`（核心）

1. 聚合离网条件 → `inv_run_flag`  
2. 聚合并网条件 → STS 连接许可  
3. connected 持续 500 次后置 `connect_run_flag`  
4. 连接前用 STS 输出调电压/频率；连接后同步源相位  
5. 写入 Inv3Ph 与 STS 的运行/连接使能  

#### `_PvWorkRunControl`

监控许可 + 母线许可 + 无内部故障 → 启动 PV。

#### `_InvStateMapUpdate`

底层 `EN_INV3PH_STATE` → 应用层 `EN_INV_STATE`。

### 3.4 对外入口

| 函数 | 调用点 | 作用 |
|------|--------|------|
| `ControlStateInit` | main Init | 待机、清许可、相序配置 |
| `Inv_State_Int1` | ISR TIME2 | STS、许可、继电器、逆变输入与状态 |
| `PcsStatePermit` | 1 ms | 低频许可、相序、FSM/监控、状态映射、调试 |
| `BackUpSwitchCtrlFunc` | 主循环每圈 | 备电开关+放电许可+负载继电器无故障+自检完成 → 合负载继电器 |

### 3.5 当前硬编码/风险点

- `_WorkPermit_ElseChk` 将并网时间、DRM 许可 **强制为 1**（未接 `GetConnectTimeEN` / `GetDrmGridConnectEN`）  
- `_WorkPermit_Force_GEnChk` 监控类型硬编码 0  
- STS connecting 许可在部分失败路径可能不显式清零（粘滞风险）

## 4. `algo_interface` — 算法适配层

### 4.1 职责

应用层与 `AlgoFw`（PV、三相逆变）之间的数据装配与控制封装；同时负责 CPU→CLA 数据镜像。

### 4.2 关键结构

- `_gPvData` / `Channel_t`：PV 总线环、功率环、多路 MPPT  
- `PvLimitInterface_t`：外部总功率/电压/电流/通道约束  
- `gstInv3phDataUpdateValue`：逆变算法输入输出接口  

### 4.3 逆变侧关键函数

| 函数 | 行为 |
|------|------|
| `Inv3PhDataUpdate` | 写母线与瞬时量；分 6 次更新 RMS/P/Q/S；第 6 次读算法输出、继电器需求、硬件过流 TZ，再 `Inv3Ph_Set_InputData` |
| `Inv3PhWorkRun` | 调 `Inv3Ph_Run` |
| `Inv3PhSetEnRun/Connect/ConnectRun` | 运行 / 并网 / 并网运行使能 |
| `Inv3PhCpuTransforClaData` | 写 `CpuToCla1MsgRAM` |
| `Get3PhIsRunFlag` 等 | 读底层状态/故障 |

### 4.4 PV 侧关键函数

| 函数 | 行为 |
|------|------|
| `PVRunSet` | PV 使能 |
| `PvVolAveRead/PvCurAveRead/PvPwrAveRead` | 读滤波后电气量 |
| `MpptSetPvPwr` | 总功率参考钳位到 `[0, total_power_max]` |
| `PvMaxPowerSet` | 设置总上限 |
| `Pv*Warning/ErrCodeRead` | 映射 PV 保护位 |

`Read_Mppt_state()` 当前返回 `mppt_state == 0`，语义需与调用方约定对齐。

### 4.5 与 CLA 的关系

CPU 侧算法算出角度、频率、参考幅值、状态后，经 `Inv3PhCpuTransforClaData` 写入共享 RAM；CLA Task1 以 20 kHz 读取并更新 EPWM1~6。详见 [11_算法层](./11_算法层_algo.md)。

/**
* @brief: CpuIntServiceFun
* @param: void
* @return:Nothing
* @note: CPU interrupt service routine
*/
void CpuIntServiceFun(void)
{
    static uint32_t  int_cont = 0;
    static uint32_t  int_cont_next = 0;

    int_cont = CpuTimer1Regs.TIM.all;
    gCpuAdcSampleTimeSlot = gstCpuInterrupt.time;
    if(gstCpuInterrupt.time <= EN_CPU_INTERRUPT_TIME_4)
    {
        gCpuTimeSlotHitCnt[gstCpuInterrupt.time]++;
    }
    GetAdcResult(gstCpuInterrupt.time);    /* Fetch ADC samples for current time slot */
    AdcGpioStateSwitch();                  /* Switch MUX before next EPWM ADC trigger */
    Cpu_Interrupt_Process();               /* Time-sliced interrupt tasks */
    int_cont_next = CpuTimer1Regs.TIM.all;
    if(int_cont > int_cont_next )
    {
        _gInterruptRunCont = int_cont - int_cont_next;
    }
    else if(int_cont < int_cont_next)
    {
        _gInterruptRunCont = int_cont + (CpuTimer1Regs.PRD.all + 1U - int_cont_next);
    }
    else
    {
        _gInterruptRunCont = 0U;
    }
}

static void _InvStateMapUpdate(void)
{
    EN_INV3PH_STATE inv_state = Get3PhRunState();
    switch (inv_state)
    {
        case EN_INV3PH_STATE_IDLE:
        {
            gstPcsInvRunState = INV_STATE_STANDBY;
            break;
        }
        case EN_INV3PH_STATE_ERR:
        {
            gstPcsInvRunState = INV_STATE_STANDBY;
            break;
        }
        case EN_INV3PH_STATE_SELFCHECK:
        {
            gstPcsInvRunState = INV_STATE_SELFTEST;
            break;
        }
        case EN_INV3PH_STATE_STARTING:
        {
            gstPcsInvRunState = INV_STATE_DISCONNECTED;
            break;
        }
        case EN_INV3PH_STATE_DISCONNECTED:
        {
            //进行并网模式设置
            gstControlAction.force_gen_connect_permit = _gMointerConnectType;
            gstControlAction.mointer_connect_type_chk = true;
            //设置STS运行切换模式
            SetStsEnForceGenMode(gstControlAction.force_gen_connect_permit);

            gstPcsInvRunState = INV_STATE_DISCONNECTED;
            break;
        }
        case EN_INV3PH_STATE_CONNECTING:
        {
            if(gstControlAction.force_gen_connect_permit)
            {
                gstPcsInvRunState = INV_STATE_GEN_CONNECTING;
            }
            else
            {
                gstPcsInvRunState = INV_STATE_GRID_CONNECTING;
            }
            break;
        }
        case EN_INV3PH_STATE_CONNECTED:
        {
            if(gstControlAction.force_gen_connect_permit)
            {
                gstPcsInvRunState = INV_STATE_GEN_CONNECTED;
            }
            else
            {
                gstPcsInvRunState = INV_STATE_GRID_CONNECTED;
            }
            break;
        }
        case EN_INV3PH_STATE_DISCONNECTING:
        {
            if(gstControlAction.force_gen_connect_permit)
            {
                gstPcsInvRunState = INV_STATE_GEN_DISCONNECTING;
            }
            else
            {
                gstPcsInvRunState = INV_STATE_GRID_DISCONNECTING;
            }
            break;
        }
        default:
        {
            gstPcsInvRunState = INV_STATE_STANDBY;
            break;
        }
    }
}

    gen_b_theta = PHASE_CNT_TO_THETA_RAD(gstPh3CalcInfo.gen_b_phase_count, gstPh3CalcInfo.gen_vol.freq);
    gen_c_theta = PHASE_CNT_TO_THETA_RAD(gstPh3CalcInfo.gen_c_phase_count, gstPh3CalcInfo.gen_vol.freq);

    if(Get_StsOutput_IsDisconnectd())
    {
        Sts_PhaseSeq_Analyze(grid_a_theta, grid_b_theta, grid_c_theta,
            gstPh3CalcInfo.grid_vol.a_phase_rms, gstPh3CalcInfo.grid_vol.b_phase_rms, gstPh3CalcInfo.grid_vol.c_phase_rms,

            gstPh3CalcInfo.gen_vol.a_phase_rms, gstPh3CalcInfo.gen_vol.b_phase_rms, gstPh3CalcInfo.gen_vol.c_phase_rms,
            &_gstGenPhaseSeq, &_gstGenPhaseSeqResult, 1);
    }
    gstControlAction.gen_phase_chk_permit = ((GetStsGenForceState() && _gstGenPhaseSeqResult.is_normal) ? 1 : 0);
    gstControlAction.grid_phase_chk_permit = ((!GetStsGenForceState() && _gstGridPhaseSeqResult.is_normal) ? 1 : 0);
}

static void _GridAndGenRelagControl(void)
{
    if(GetStsGenForceState())
    {
        RelayControl(EN_RELAT_CTRL_TYPE_GRID, false);
    }
    else
    {
        RelayControl(EN_RELAT_CTRL_TYPE_GEN, false);
    }
    if(Get_StsOutput_RelagState())
    {
        if(GetStsGenForceState() && !GetRelayState(EN_RELAT_CTRL_TYPE_GEN))
        {
            RelayControl(EN_RELAT_CTRL_TYPE_GEN, true);
        }
        else if(!GetStsGenForceState() && !GetRelayState(EN_RELAT_CTRL_TYPE_GRID))
        {
            RelayControl(EN_RELAT_CTRL_TYPE_GRID, true);
        }
    }
    else
    {
        RelayControl(EN_RELAT_CTRL_TYPE_GEN, false);
        RelayControl(EN_RELAT_CTRL_TYPE_GRID, false);
    }
    if(GetErrorFlag() != 0)
    {
        RelayControl(EN_RELAT_CTRL_TYPE_GEN, false);
        RelayControl(EN_RELAT_CTRL_TYPE_GRID, false);
    }
}
