# 01 系统架构与运行时序

## 1. 产品定位

本工程为 **Roca 系列三相混合储能 PCS（Power Conversion System）的 CPU1 固件**，运行于 TI **TMS320F28375D** 双核 DSP。CPU1 负责：

- 外设驱动与 ADC 采样调度
- 快速保护与慢速保护
- 业务状态机、能量管理、监控通信
- 与 CPU2 协作完成三相测量/STS
- 驱动 CLA 完成 20 kHz 逆变实时控制

CPU2（另一工程）负责三相 PLL/功率计算与 STS 算法，经 GS 共享 RAM 与 CPU1 交换数据。

## 3. 四类执行上下文

| 上下文 | 频率/触发 | 典型工作 |
|--------|-----------|----------|
| 启动初始化 | 上电一次 | `main()` 硬件与业务 Init、引导 CPU2 |

## 4. 核心数据流

```
ADC 寄存器
   ↓ GetAdcResult (时隙 TIME0~4)
gstAdcResult / gstClaAdcResult
   ↓ IPC 触发 CPU2
CPU2 三相计算 + STS
   ↓ GS 共享 RAM
gstPh3CalcInfo / STS 输出
   ↓
保护(fault) / 控制许可(control_state) / 能量管理 / 上传(sys_info)
   ↓
Inv3Ph / PV / 继电器 / 监控 UDP·Modbus
```

控制命令流：

```
监控(UDP/Modbus/SCI)
   → gstUdpPcsPara 持有寄存器
   → Biz FSM / 能量调度 / control_state
   → Inv3Ph、PV、STS、继电器
```

## 5. ADC 时隙与 ISR 分工

CPU ISR 内用 `TIME0~TIME4` 轮转：

| 时隙 | 采样侧重 | ISR 附加任务 |
|------|----------|--------------|
| TIME0 | 逆变电压/电流、CT、漏电流 | — |
| TIME1 | 电网、PV1 | `Ph3CalcInfo_Update`、触发 CPU2、心跳 |
| TIME2 | 油机、PV2、正母线 | `Inv_State_Int1`、SCIA 收 |
| TIME3 | 负载、PV3、母线电流 | 逆变快故障、`SCIC` 收 |
| TIME4 | 继电器中点电压 | `SCIB` 收；进入时触发 `FastErrWarningHandler` |

MUX GPIO（34/35/40/41）在 ISR 中切换，保证下一时隙模拟通道就绪。

## 6. 主循环周期任务（`main.c`）

| 周期 | 任务 |
|------|------|
| 每圈 | `ProtocolProcess`、`CpuTimerFlag`、LED、备电继电器 |
| 1 ms | CT 方向、能量数据更新与调度、PCS 许可、温度 MUX、调试发送 |
| 10 ms | `BizFsm_Interface_Update` |
| 20 ms | 慢速故障、电量累计 |
| 100 ms | 风扇；每 200 ms `Pv_Mppt_Run` |
| 1 s | `Pv_Set_Pwr_Limit(26400 W)`（当前硬编码） |

## 8. 双核协作概要

1. `DualCore_InitEarly`：分配 GS RAM / 外设归属  
2. `DualCore_BootCpu2WithTimeout` + `Handshake`  
3. `DevDcr_ExchangeAddress`：交换三相接口、STS、调试地址  
4. `DualDataShare_UpdatePh3Cmd`：打开 CPU2 计算使能  
5. 运行期：TIME1 触发 IPC；心跳检测 CPU2 在线

共享区要点：

- CPU1→CPU2 消息：约 `0x3FC00`
- CPU2→CPU1 消息：约 `0x3F800`
